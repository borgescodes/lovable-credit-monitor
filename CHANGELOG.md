# Changelog

All notable release information that can be verified from the supplied project archive is documented here.

## [0.7.2] - 2026-08-24

Current portfolio release.

- Uses Lovable `Settings > People` as the authoritative source for personal monthly usage and credit limit.
- Supports Full, Compact, Minimal and Ring views.
- Includes Original, Red, Juparana and Black & White palettes with Auto, Light and Dark appearance modes.
- Reuses an existing People tab when possible and supports manual synchronization.
- Keeps usage and UI state in `chrome.storage.local`.
- Preserves edge-aware panel positioning while views resize.
- Respects `prefers-reduced-motion`.
- Uses Manifest V3 with only `storage` and `alarms` extension permissions plus Lovable host access.

Designed to stay out of the way

Useful signal. Minimal interference.

01
↻

Passive People sync

Reads only the row marked (you) from Settings > People and uses the monthly usage and credit limit already shown by Lovable.

02
⌂

Local-only state

No project-owned server or account. Usage snapshots, sync state and UI preferences remain in chrome.storage.local.

03
◫

Four compact views

Move from a detailed Full panel to Compact, Minimal or a 60px Ring when screen space matters more than detail.

04
↔

Edge-aware placement

When the monitor changes size near a viewport edge, it preserves that edge distance and grows back into the workspace.

05
◉

Manual Sync

Reuse an existing People tab or create one in the background only when you explicitly need an updated official value.

06
∿

Reduced motion aware

View transitions, count-up and progress feedback automatically respect the operating system reduced-motion preference.

Privacy by construction

No analytics.
No extension backend.

Credit Monitor is intentionally small in scope. It reads the Lovable People view, stores the result in your browser and renders the monitor locally.

  • ✓No fetch/XHR interception
  • ✓No route automation or synthetic clicks
  • ✓No keyboard-event injection
  • ✓No project-owned telemetry
